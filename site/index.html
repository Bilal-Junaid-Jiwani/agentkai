How it works

Three steps to your agent.

No cloud account, no subscription, no black box. You bring the model; agentkai brings everything else.

01

Connect a model

One provider layer (LiteLLM) talks to 100+ models. Set a key and pick an alias: claude, gemini, gpt, glm — or local for free offline Ollama.

02

Give it tools & memory

Safe shell, real Chromium browser, 12 bundled skills, subagents — and memory as plain markdown files you can read, edit, and version with git.

03

Talk from anywhere

Terminal, local web dashboard, or your phone: the messaging gateway bridges Telegram, Discord, WebChat, and WhatsApp to the same agent.

Features

Built like you'd build it.

Local-first, honest about limits, and every moving part is inspectable.

Your models, your keys

agentkai ships no model of its own — it never could lock you in. Aliases resolve per run, per job, or per channel, with fallbacks when a provider hiccups.

  • agentkai models shows aliases and which keys are set
  • 100+ models through one LiteLLM provider layer
  • Fully local option: Ollama, no key, no network, no cost
terminal
# bring your own key
export ANTHROPIC_API_KEY=sk-ant-...
agentkai models
claude   → anthropic/claude-sonnet-4-5   ✓ key set
gemini   → gemini/gemini-2.5-flash        ✓ key set
local    → ollama/qwen3:32b               ✓ local
# or skip keys entirely
agentkai run "summarize this folder" --model local

It actually remembers

Memory is plain markdown in ~/.agentkai/memory/ — no database, no embeddings service, no black box. Read every file, edit by hand, commit to git.

  • SOUL.md + USER.md — who the agent is, who you are
  • Daily logs, people pages, long-term MEMORY.md
  • Nightly "dreaming" consolidates the day into durable memory
~/.agentkai/memory
memory/
├── MEMORY.md        # durable facts
├── SOUL.md          # agent persona
├── USER.md          # about you
├── 2026-10-01.md    # daily log
└── people/
    ├── INDEX.md
    └── muhammad-araf.md
# git init && git commit — your call

Works while you sleep

Cron-style recurring jobs, one-shot timers, a heartbeat check-in, and nightly dreaming — stored in SQLite so they survive restarts.

  • scheduler add / list / run-once / remove
  • Dashboard UI: add jobs, run now, delete, inspect history
  • Unattended safety: jobs can never prompt — high-risk tools are denied, not asked
scheduler
# every weekday at 7:00
agentkai scheduler add morning-brief \
  --schedule "0 7 * * 1-5" \
  --prompt "Summarize today's calendar and unread email."
# one-shot
agentkai scheduler add dentist --at 2026-10-02T09:00 \
  --prompt "Remind me to leave for the dentist."
$ agentkai scheduler list
morning-brief   cron 0 7 * * 1-5   next: tomorrow 07:00
dentist         at   2026-10-02T09:00

CLI

One command, everything.

Eleven commands cover the whole agent. These are real — try them.

# run one agent task, streaming
agentkai run "list the files in my home directory and summarize what this machine is for"
# → the answer streams as the model thinks; medium/high-risk tools ask first
# pass -y to auto-approve, only when you trust the task
